# Thamak Supply Chain Analytics
## Portfolio Case Study

### Business Problem

Vanilla export businesses face seasonal supply, curing lead times, supplier quality variations and customer demand throughout the year. These factors create challenges for procurement planning, inventory management and customer fulfilment.

### Project Objective

To develop a simulated supply chain analytics solution that demonstrates how data can support procurement decisions, supplier evaluation, inventory control and profitability analysis.

### Tools Used

- PostgreSQL — data storage, SQL queries and analysis
- Python — simulated data generation and validation
- Power BI — planned dashboard development
- GitHub — version control and project documentation

### Key Findings

| Metric | Result |
|---|---:|
| Total customer demand | 1,290.9 kg |
| Quantity fulfilled | 985.7 kg |
| Fulfilment rate | 76.36% |
| Unfulfilled opening demand | 305.2 kg |
| Shipped sales revenue | £103,750.79 |
| Estimated landed cost | £66,763.92 |
| Gross profit | £36,986.86 |
| Gross margin | 35.65% |
| Closing inventory | 874.7 kg |
| CoA pass rate | 60% |

### Business Recommendations

1. Align procurement with harvest seasons and curing lead times.
2. Monitor inventory against expected customer demand.
3. Evaluate suppliers using cost, delivery reliability and quality results.
4. Investigate unmet demand and distinguish opening backlog from later fulfilment performance.
5. Review profitability by customer segment and product grade.

### Data Disclaimer

This project uses simulated data based on a realistic vanilla export supply chain. Supplier names, customer names, transactions and financial figures are fictional and created for analytical demonstration.

The results illustrate analytical methods and are not verified commercial performance.
